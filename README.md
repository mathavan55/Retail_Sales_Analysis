# Retail Sales Analysis Dashboard

A Power BI project focused on analyzing retail sales data and generating business insights through interactive visualizations and dashboards.

---

# 📌 About The Project

This project analyzes retail sales transactions to identify:
- High-selling product categories
- Monthly sales trends
- Customer purchasing behavior
- Gender-based product preferences
- Quantity sold analysis

The dashboard was developed using Power BI to transform raw retail data into meaningful visual insights for better business understanding and decision-making.

---

# 🚀 Features

✅ Interactive Power BI Dashboard  
✅ Monthly Sales Analysis

✅ Gender-Based Sales Analysis  
✅ Quantity Sold Analysis

# 📂 Dataset Information

The dataset contains retail transaction details such as:

| Column Name | Description |
|---|---|
| Transaction ID | Unique transaction ID |
| Gender | Customer Gender |
| Age | Customer Age |
| Product Category | Product Type |
| Quantity | Quantity Purchased |
| Price Per Unit | Product Price |
| Total Amount | Total Sales Amount |
| Month | Sales Month |

## Quantity Sold Analysis

## Interactive Slicers

---

# 📈 Key Insights

- Electronics category generated the highest sales revenue
- Clothing products recorded high quantity sales
- Sales performance varied across different months
- Male and female purchasing patterns were nearly balanced
- Certain product categories performed better for specific genders
